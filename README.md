## Project Description:
Campus Cravings displays daily promotions, pricing information, and student generated ratings and reviews for nearby restaurants. Users can also view information about the University Plaza restaurants such as address, contact information, cuisine. 

By consolidating this information in one place, Campus Cravings aims to help students make cost-effective dining decisions efficiently.
